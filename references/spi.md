# SPI3（リクルートマネジメントソリューションズ）

日本最普及的招聘适性检查，覆盖各行各业。识别为 SPI 后，解法见 `solutions/spi-nonverbal.md` 与 `solutions/spi-verbal.md`。

## 出题形式（4 种，特征不同）

| 形式 | 场所 | 特征 |
|---|---|---|
| **テストセンター** | 指定会场 / 在线监考 | 正答会影响下一题难度（IRT），常见「組問」一题多问；电脑作答 |
| **WEBテスティング** | 自宅 PC | 在家作答，有「熟語の成り立ち」「文の並べ替え」等专属题型；可用草稿纸 |
| **インハウス CBT** | 企业内 PC | 企业现场电脑作答 |
| **ペーパーテスティング** | 企业 / 会场纸笔 | マークシート，题序固定 |

> 同一道知识点在不同形式下出题略有差异，但解法通用。テストセンター不能回看上一题。

## 科目

- **能力検査**：言語（语文）+ 非言語（数理）。
- **オプション**：英語（ENG）、構造的把握力検査（部分企业）。
- **性格検査**：约 300 问，分多个维度 → 见 `references/personality.md`。

## 非言語（数理）题型清单

判型关键词 → 解法都在 `solutions/spi-nonverbal.md`：

- **推論**（順序・位置・対応・正誤・うそつき）— SPI 最核心、出现率最高
- **場合の数**（順列・組合せ）
- **確率**
- **集合**（2～3 集合，ベン図）
- **損益算**（原価・定価・売価・利益・割引き）
- **速度算**（速さ・距離・時間、旅人算、通過算）
- **仕事算**（全体を 1 とおく）
- **割合と比 / 濃度（食塩水）**
- **料金・割引・代金の精算（割り勘）・分割払い**
- **年齢算 / 鶴亀算 / 過不足算**
- **表・資料の読み取り**
- **n 進法 / 物の流れ（WEBテスティング 偏多）**

## 言語（语文）题型清单

判型关键词 → 解法都在 `solutions/spi-verbal.md`：

- **二語の関係**（同义・反义・包含・役割・原料・一組・並列…）— 高频
- **語句の意味**（词义）
- **語句の用法**（多义词、助词・文法用法）
- **文の並べ替え**（文节整序 / 文章整序）
- **空欄補充**（接続語・適語）
- **長文読解**（内容一致・主旨・指示語）
- **熟語の成り立ち**（WEBテスティング 专属）

## 判型 / 与其他测试区分

- 出现「**推論**」（条件推断顺序/真假）、「損益算」「速度算」「二語の関係」→ 基本是 SPI。
- 若是"同一题型连续大量、时间极短、四則逆算□"→ 更像**玉手箱**，转 `references/tamatebako.md`。
- 若是图形逻辑（法則性・命令表・暗号）→ **CAB**，转 `references/gab-cab.md`。

## 时间与策略

- 能力検査整体有时间限制，テストセンターは設問ごと/組ごとに目安时间，**答完即不可改**。
- 非言語：先抓「推論」「損益・速度・割合」三大块的速度。
- 言語：「二語の関係」「語句」要靠平时积累瞬答，把时间留给長文。
- 性格検査：求一致性、勿过度伪装 → `references/personality.md`。

## 备考优先级（给计划时参考）

1. 非言語：推論 → 損益算/速度算/割合 → 場合の数/確率 → 集合/仕事算
2. 言語：二語の関係 → 語句 → 並べ替え/空欄 → 長文
3. 性格：了解作答策略即可，重在一致性
