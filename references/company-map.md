# 企业 → 测试 对照（倾向参考 + 自查方法）

> ⚠️ **重要**：哪家公司用哪种测试**每年都可能变**（同公司不同年度/不同职种也会换）。
> 本页只给**行业级倾向**和**自查方法**，引用时务必提醒用户**以最新信息为准**。

## 行业级倾向（仅供参考方向）

| 行业 | 较常见的测试倾向 |
|---|---|
| 综合商社 / 大型金融·证券 | **玉手箱 / GAB / C-GAB** 偏多 |
| 银行·保险 | 玉手箱、SPI 都常见 |
| 咨询 | 玉手箱、GAB、TG-WEB、独自筆記 都可能；外资偏英语·难度 |
| メーカー（制造业） | **SPI** 偏多，也有玉手箱 / TG-WEB |
| IT / SI / SE 职 | **CAB / Web-CAB**，或独自**编程测试**（另一类，非本表） |
| 广告·マスコミ | 独自色彩强，玉手箱 / TG-WEB / 独自筆記 |
| 公务员·部分团体 | SCOA、独自 |

> 这只是大致风向，**不能据此断定某具体公司用什么**。

## 怎么自查（最可靠）

1. **过去问 / 口コミサイト**：みんなの就職活動日記（みん就）、ONE CAREER、unistyle、就活会议 等，搜"<公司名> Webテスト 種類 <年度>"。
2. **看受验形式**：
   - 自宅 Web、同一题型连刷、有四則逆算□ → 玉手箱系
   - 指定会场/在线监考、组问、能回头难度自适应 → SPI テストセンター
   - 图形法則性/命令表/暗号 → CAB
   - 展開図/軌跡难图形 → TG-WEB 従来型
3. **看受验链接的域名**：业内流传"不同测试的受验 URL 域名不同，可大致判别"。**但域名会变**，仅作辅助，最终以实际题型为准——不要只凭一个域名下结论。
4. **看邀请邮件措辞 / 制限時間 / 题数**：与各测试的典型配置对照（见各 `references/<test>.md`）。

## 给用户的话术建议

当用户问"X 公司是什么测试"时：
- 先给**行业倾向**作为方向；
- 强调**务必用上面的方法核对当年实际情况**；
- 若用户能贴出邀请邮件/受验页面/样题，按 `SKILL.md` 的判型流程帮其判断当前实际题型，比任何对照表都准。
