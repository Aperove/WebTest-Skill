# TG-WEB（ヒューマネージ）

外资、コンサル、メーカー、部分知名企业采用。最大特点：分**従来型**与**新型**，两者难度·风格差别很大，先判是哪型。

识别后解法见 `solutions/tg-web.md`（图形类）与 `solutions/spi-verbal.md`/`solutions/calc-shortcuts.md`（言語/计算可复用）。

## 従来型（难·题量少）

"没见过就很难当场想出来"的类型，靠**事先认套路**。

- **計数**：
  - 図形（面积·角度·分割·重叠）
  - **展開図**（立方体/多面体的展开与还原）
  - **軌跡**（图形滚动时某点的轨迹）
  - **推論 / 集合 / 数列 / 暗号**
- **言語**：
  - **長文読解**（空欄补充·内容一致）
  - **文の並べ替え（整序）**
  - 同义/反义、慣用句

## 新型（易·题量多·拼速度）

风格更接近 SPI/玉手箱，**简单但要快**。

- **計数**：四则计算、図表の読み取り、割合、推論
- **言語**：長文、空欄補充、語彙

## 其他

- **英語**（部分企业）
- **性格**：ヒューマネージ独自（A8 / G9 / T4 等），含「计算能力·ストレス耐性」类 → `references/personality.md`
- 部分含**简易计算/事務処理**类。

## 判型

- 看到**展開図·軌跡·折り紙·难図形** → 基本是 **TG-WEB 従来型**（CAB 也有图形，但 CAB 是法則性/命令表/暗号那一套，不考展開図·軌跡）。
- 题目"简单但巨多、限时紧" → **TG-WEB 新型**（与玉手箱区分：玉手箱有四則逆算□和 A/B/C 三択，TG-WEB 新型一般没有）。

## 策略

- **先确认型号**：従来型重"认套路+图形功底"，新型重"速度"。备考方向完全不同。
- 従来型展開図/軌跡：背熟立方体相对面规律、滚动一周轨迹形状，临场套用。
- 言語並べ替え：抓接续词、指示语、主谓对应来定相邻关系（详见 `solutions/spi-verbal.md`）。
