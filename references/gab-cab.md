# GAB / C-GAB 与 CAB / Web-CAB（日本 SHL）

同属 SHL 的两条线：**GAB = 综合职适性**（文字+数理），**CAB = IT/エンジニア适性**（图形逻辑）。
注意区分。

---

## GAB / C-GAB / Web-GAB

面向**总合商社、金融、证券、综合研究所**等综合职。题型与玉手箱同源但更难。

| 版本 | 实施 |
|---|---|
| **GAB** | マークシート（纸笔） |
| **Web-GAB** | 自宅 Web |
| **C-GAB** | テストセンター（监考会场） |

**科目**：
- **言語**：長文の論理的読解（**A=正しい / B=誤り / C=判断できない** 三択，与玉手箱同套路）
- **計数**：図表の読み取り（图表数值计算，比玉手箱更复杂）
- **英語**（部分）、**性格**（OPQ）

> 解法直接复用 `solutions/tamatebako.md`（論理的読解 A/B/C、図表读取）。GAB 的长文更长、图表更绕，重在稳和速度。

---

## CAB / Web-CAB

面向 **SE・プログラマ・IT 职**，测的是逻辑·处理能力，**几乎全是图形/数列逻辑**。

| 版本 | 实施 |
|---|---|
| **CAB** | マークシート |
| **Web-CAB** | 自宅 Web |

**科目（4 类能力 + 性格）**：

| 题型 | 内容 | 解法 |
|---|---|---|
| **暗算** | 四则运算速算，选最接近 | `solutions/cab.md` + `solutions/calc-shortcuts.md` |
| **法則性** | 一组图形按某规律排列，选填空处应有的图形 | `solutions/cab.md` |
| **命令表** | 图形经一连串「命令（旋转/翻转/换色/移动）」后的结果 | `solutions/cab.md` |
| **暗号** | 由"图形 A → 图形 B"反推命令（暗号），再应用到新图形 | `solutions/cab.md` |
| 性格 | OPQ + コンピュータ職适性 | `references/personality.md` |

## 判型（区分 GAB vs CAB vs 其他）

- 长文 + 图表数值、A/B/C 三択 → **GAB**（综合职）。
- 一连串**图形变换 / 找图形规律 / 暗号** → **CAB**（IT 职）。
- 若图形里出现「展開図·軌跡·折り紙」难题，更可能是 **TG-WEB 従来型** → `references/tg-web.md`。

## 策略

- CAB 法則性/命令表/暗号：**先固定"每一步在变什么属性"**（位置·方向·颜色·数量），逐属性追踪比整体看更稳。
- 暗算：練速算与"选最接近"的概算 → `solutions/calc-shortcuts.md`。
- GAB：把长文 A/B/C 判定练成机械流程，避免纠结。
