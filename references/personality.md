# 性格検査 通用对策

几乎所有 Webテスト 都附带性格检查（SPI 性格、玉手箱/GAB/CAB 的 OPQ、TG-WEB 独自、TAL、クレペリン 等）。
**没有"标准答案"**，但有合理的应对原则。

## 它在测什么

- 把你的回答归到若干维度（SPI：行動・意欲・情緒・社会関係 等多个側面；OPQ：30 余个特质）。
- 多数含**ライスケール（虚偽·矛盾检测）**：用正反措辞的重复题、社会期望题，抓**前后不一致**和**过度美化**。
- 结果用于：**与企业「求める人物像」的匹配度**、面接时的提问参考、个别岗位的适性。

## 核心原则（既诚实又不吃亏）

1. **一致性最重要**：同一倾向的题，作答要稳定。自相矛盾会触发虚偽尺度，比"某项分数不高"更糟。
2. **基于真实的自我，但带着岗位意识回答**：先了解目标岗位/企业看重什么（如营业重"対人積極性"、研究职重"慎重·探究"），在**真实范围内**选更贴近的一端，而不是凭空编造一个不是你的人。
3. **别全选中间/极端**：通篇"どちらともいえない"会被读成回避；通篇极端则不自然。
4. **别过度伪装**：装出与本性差太远的形象，①容易矛盾露馅 ②即便过了，进了不合适的岗位也痛苦。
5. **控时、别留空**：题量大（SPI 约 300 问），靠直觉稳定作答，按节奏走完。

## 各测试的性格部分

| 测试 | 性格形式 | 备注 |
|---|---|---|
| SPI | 约 300 问，4 大側面多维度 | 多为"A 寄り/B 寄り"程度选择 + 是非 |
| 玉手箱 / GAB / CAB | **OPQ**（本格/簡易） | "最も近い/最も遠い"四选二式较常见 |
| TG-WEB | ヒューマネージ独自（A8/G9/T4） | 含ストレス耐性等 |
| TAL | 图形贴付 + 质问 | 重在排除风险人物 → 保持正向一致 |
| 内田クレペリン | 连续加法的作业曲线 | 练稳定节奏即可 |

## 备考建议

- 事先做一次**自我分析**（强项、动机、价值观），并对照目标企业的「求める人物像」。这样答题既真实又一致，是最稳的"对策"。
- 把性格检查当成"让企业判断双向匹配"的工具，而非纯粹闯关——匹配错了对你也不利。
- 想聊"某岗位倾向看重哪些特质、怎么在真实范围内呈现"，可以直接问，我按岗位给具体维度建议。
