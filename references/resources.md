# 参考资源（做题时查资料用）

做题/备考时可查的外部资源精选。**用法**：这些日本就活站多数**屏蔽自动抓取**，所以由用户在**浏览器**打开；skill 负责讲解与解题，并可用 **WebSearch** 帮你查最新信息（"X 公司 2026 Webテスト 種類"之类）。

> ⚠️ 链接与内容**会随年份变动**，免费题量/是否需注册也可能调整，以打开后实际为准。

## 使用提示

- 想"查某题型怎么解" → 优先 **じょうしき.com**（按题型例题）、**Noah's Ark**（解説付き）。
- 想"这家公司考什么" → 先看 **ワンキャリア / OfferBox** 的見分け方，再用 WebSearch 查当年口コミ。
- 让 skill 帮你时：直接把题目（文字或截图）贴来，按 `SKILL.md` 流程核对/讲解，比逐个翻网站更快。
- 需要最新信息（年度变化、新出测试）→ 让 skill 用 WebSearch 查，并注明信息日期。
