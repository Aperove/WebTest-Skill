# CAB / Web-CAB 解法（图形逻辑）

CAB 测 IT/SE 适性，几乎全是图形与速算。核心方法：**逐属性追踪**，别整体凭感觉看。

---

## 暗算

连续四则速算，多为"选最接近"。
- 用**概算 + 末位检验**：先估数量级与首位，再用个位数排除错项。
- 详见 `solutions/calc-shortcuts.md`（概算、约数、末位法）。
- 节奏稳定优先，别在单题死磕。

---

## 法則性（找规律填图）

一排图形按某规律排列，选**空缺处**应有的图形。

**方法：逐属性独立追踪**。把图形拆成可变属性，分别看每个属性的变化规律：
- **位置 / 方向**（旋转角度：每步 +90°？顺/逆）
- **数量**（点·线·边的个数递增/递减）
- **形状 / 种类**（按某顺序循环）
- **颜色 / 填充**（黑白交替？阴影移动）
- **大小**

逐属性推出空缺处各属性的值，再合成 → 对照选项。

> 关键：**一次只盯一个属性**，全部锁定后再合并，避免被整体形状迷惑。

---

## 命令表（按命令变换图形）

给初始图形 + 一串**命令**，求最终结果（或反推某步）。

**方法：逐命令、逐步画出中间状态**，别跳步。常见命令含义：
- **回転**（90°/180°，顺/逆时针）
- **反転**（上下/左右镜像、line 对称）
- **色反転**（黑白互换）
- **移動 / シフト**（元素整体平移）
- **追加 / 削除 / 置換**（增删或替换某元素）

> 一步一画，每步只应用一个命令。命令表常给出"命令符号→操作"的对照，先把符号意义抄下来再执行。

## 暗号（CAB 最难题型）── 特攻

给一个**暗号キー（key 图）**：若干「图形A →[暗号]→ 图形B」的对应。每个暗号符号 = 一个**固定操作**。
要先**破译每个暗号**，再在设问里**正向应用**或**逆向反推**。

### 特攻六步

1. **先填メモ栏：逐个破译暗号 → 写下"它在做什么"**。破译一次、全程套用，别每题从头看。

2. **逐属性分解（最关键）**：把图形拆成相互独立的属性分别追踪。常见属性：
   - **方向 / 旋转**（整体转了几度，顺/逆）
   - **黑白（色の反転）**
   - **哪个区域被涂黑 / 阴影位置**
   - **元素的有无·增减·移动**
   一个暗号通常只改 **1 个**属性（偶有 2 个）。对比 A 与 B，只问"哪个属性变了、怎么变"。

3. **先吃"只过一个暗号"的对应**：键图里若有「A →[单个暗号]→ B」，直接读出该暗号含义，最省力。

4. **网格 / 链式三角定位**：若一条路径串了两个暗号「A →[暗号1]→[暗号2]→ B」，单看只得到二者的**合成**。
   利用**同一暗号也出现在另一行/列**：找两条**只差一个暗号**的路径对比，即可隔离它。
   （2×2 暗号键正是这样：每个暗号同时落在某"行"和某"列"，两两交叉就能逐个钉死。）

5. **设问三形态 → 三种做法**：
   | 设问 | 形态 | 做法 |
   |---|---|---|
   | 求**最终图形** | `输入 →暗号→暗号→ ?` | **正向**：把暗号按序施加到输入，逐步画中间态 |
   | 求**输入图形** | `? →暗号→暗号→ 输出` | **逆向**：从输出倒着走，对每个暗号施加**逆操作** |
   | 求**暗号本身** | `输入 →?→ 输出`（选项是暗号符号）| 算输入↔输出的**净变化**，匹配等效的暗号（或暗号对）|

6. **検算**：破译出的暗号要在它出现的**所有**对应里都成立（交叉验证），防止读错某张图的黑白。

### 逆向反推的关键技巧（求输入图形时）

- **色反転、上下/左右反転、180°旋转 都是"自反"**：逆操作 = 它本身，**倒着走和正着走一样**。
- 只有**90°旋转 / 平移 / 有方向性**的操作，逆向时要**取反方向**（顺↔逆、左↔右）。
- 所以遇到"求输入"，先把暗号序列里"自反"的照原样施加，"有方向"的反方向施加即可。

> 与命令表互逆：命令表是"已知操作求结果"，暗号是"已知结果求操作再套用"。两者都靠**逐属性比对**最稳。
> 想找此类例题练手 → `references/resources.md`（じょうしき.com 按题型例题、Noah's Ark 解说付き Web-CAB）。

## 通用策略

- **逐属性 / 逐步骤**是 CAB 一切图形题的通法。
- 先把"每一步在改变哪个属性"写/记下来，再机械执行，比整体直觉快且准。
- 暗算靠概算提速，图形靠拆解提准。
