# SPI 言語 解法

言語靠"积累 + 套路"。瞬答的题（二語の関係·語句）省下时间给長文。

---

## 二語の関係（高频）

先判断给定一组词的**关系类型**，再在选项里找**同关系**的一组。常见关系：

| 关系 | 例 |
|---|---|
| 同义 | 永久 ─ 恒久 |
| 反义 | 需要 ─ 供給 |
| 包含（上位/下位） | 動物 ─ 犬 |
| 役割（用途） | はさみ ─ 切る |
| 原料 | パン ─ 小麦 |
| 一組/セット | 針 ─ 糸 |
| 並列（同类） | 赤 ─ 青 |
| 物 ─ 場所 | 本 ─ 図書館 |
| 行為 ─ 対象 | 運転 ─ 自動車 |

**方法**：用一句话把关系说死（"A は B の原料"），再代入各选项，**唯一同型**者即答案。注意方向（A:B vs B:A 要一致）。

---

## 語句の意味

考词义。方法：
- 把词放进**自然短句**里体会语感。
- 看**汉字构成**推义（熟语多可拆解）。
- 用排除法去掉明显不符的。
> 平时靠积累；不确定时给出最可能项并标注不确定。

---

## 語句の用法

考**多义词**或**助词/语法**的同用法辨别。
- 多义动词（「みる」「とる」「かける」等）：判断**原意 vs 引申义**，选用法相同的句子。
- 助词（「の」「に」「で」）：判断其**语法功能**（主格/连体/对象/场所/手段…），选功能一致者。

---

## 文の並べ替え（整序）

文节整序 / 文章整序。**靠衔接线索定相邻关系**：
1. **接続語**（しかし・だから・また・つまり）指示前后逻辑。
2. **指示語**（その・これ・そう）必指前文已出现的内容 → 不能放句首。
3. **主述·助词呼应**（「は」提示的主题、「を/が」的对象）。
4. 先定**开头**（常是总述/背景）和**结尾**（常是结论），再补中间。

> 小技巧：先找"绝对相邻"的两块拼成大块，缩小排列空间。

---

## 空欄補充

- **接続語补充**：判断空格前后是顺接/逆接/并列/换言，选对应连词。
- **適語/適文补充**：靠上下文语义与呼应，选使全文连贯者。

---

## 長文読解

- **先读设问**，带着问题回原文定位，别通读浪费时间。
- **内容一致**：逐项回原文核对，警惕"言い過ぎ（绝对化）""すり替え（偷换）""本文未提及"。
- **指示語/接続語**题：回指示词上一句找指代。
- **主旨**题：抓**笔者主张句**（常在転換接続词后、段末、文末）。

> 与玉手箱/GAB 的 A/B/C 三択不同，SPI 长文是普通的内容一致/主旨选择；A/B/C 判定见 `solutions/tamatebako.md`。

---

## 熟語の成り立ち（WEBテスティング 专属）

判断二字熟语的构成类型，常见五类：
1. **似た意味**の漢字を重ねる（豊富、温暖）
2. **反対の意味**の漢字（高低、売買）
3. **上が下を修飾**（青空、急増）
4. **下が上の目的語·補語**（読書=書を読む、登山）
5. **主述関係**（地震=地が震える、年長）

把两个汉字的关系套进这五类即可。
