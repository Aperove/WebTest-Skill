# 玉手箱 / GAB 解法

玉手箱·GAB 同源，解法通用。核心是**速度**与**A/B/C 判定的稳**。

---

## 計数①　四則逆算（求 □）

把含 □ 的算式当方程，**移项**解 □。每题目标约 10 秒。

**移项规则**：
- `□ + a = b` → `□ = b − a`；`□ − a = b` → `□ = b + a`
- `□ × a = b` → `□ = b ÷ a`；`□ ÷ a = b` → `□ = b × a`
- `a ÷ □ = b` → `□ = a ÷ b`（□ 在分母，结果是 a/b）

> 小例：`□ × 4 = 200` → □ = 50。`□ ÷ 8 = 3` → □ = 24。`72 ÷ □ = 9` → □ = 8。
> 复杂式先合并已知数再移项；小数/分数先化简。善用 `solutions/calc-shortcuts.md`。

## 計数②　図表の読み取り

给图/表 + 设问，做数值计算（增减率、构成比、倍率、人均…）。

**提速法**：
1. **先读设问**，明确要算什么、用哪几个数。
2. **只取需要的数**，别通读全表。
3. **概算优先**：选项差距大时用有效数字概算即可（详见 `calc-shortcuts.md`）。
4. 常见量：增减率 `(今−前)/前`、构成比 `部分/全体`、倍率 `A/B`。

> 注意单位与"千/万/百万"的位数，别看错纵轴刻度。

## 計数③　表の空欄推測

表里数值**有某种规律**，推测空欄的近似值。**答案常非整数，选最接近**。

**找规律的顺序（逐个试）**：
1. **行方向 / 列方向的差**是否恒定（等差）。
2. **比 / 倍率**是否恒定（等比）。
3. 与**相邻列/某一列的运算关系**（和、差、积、商、比例）。
4. **两列之积或比近似常数**（反比例）。

> 方法：先在已知行验证你猜的规律成立，再用同规律算空欄，最后选最接近的选项。不必精确。

## 言語①　論理的読解（GAB 形式）── A/B/C 判定

读本文，对每个设问判 3 选 1：

| 选项 | 含义 | 判定要点 |
|---|---|---|
| **A** | 本文から**論理的に正しい** | 仅凭本文就能**必然推出** |
| **B** | 本文から**明らかに誤り** | 与本文**直接矛盾** |
| **C** | 本文だけでは**判断できない** | 本文**没提到 / 信息不足 / 需外部常识才能判断** |

**铁律**：
- **只能用本文信息**，不能用自己的常识/世界知识去补。需要"常识补全"才成立的 → **C**。
- 设问比本文**说得更强/更绝对**（全部・必ず・最も…而本文没这么说）→ 往往 **C**（信息不足），除非与本文明确冲突才 B。
- 设问与本文**明确相反** → **B**；本文**直接支持** → **A**。
- 最易错：**B 与 C 混淆**。"本文に書いていない" ≠ "誤り"。没写到 = C，不是 B。

> 流程：定位本文相关句 → 问"光靠这句能不能必然得出设问？" 能→A；得出相反→B；得不出/没依据→C。

## 言語②　趣旨判断（IMAGES 形式）

判断设问句**是否符合筆者の主张/趣旨**（合致 / 不合致 等）。
- 抓**笔者的主张句**（主张常在転換接続词后、段末、文末）。
- 只是"本文里提到过的事实"但**非笔者主张** → 不算合致。
- 与主旨方向一致 = 合致；偏离/相反/仅细节 = 不合致。

---

## 言語③　趣旨把握

从选项中选**最能概括全文主旨**者。
- 排除"过窄（只覆盖一段/一例）"和"过宽/跑题"的选项。
- 选覆盖笔者核心主张、范围恰当的那个。

---

## 通用策略

- **速度训练**：四則逆算练到看一眼就移项；図表先看设问。
- **言語求稳**：A/B/C 宁可慢一拍判准，错判很伤分。
- 自宅受験可用计算器/草稿，但熟练度才是瓶颈。
