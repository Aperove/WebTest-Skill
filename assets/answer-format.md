# 输出格式模板（答案核对 / 详解）

根据 `SKILL.md` 工作流第 4 步，按本轮模式选用下列模板。

---

## 模式 A：只核对答案（紧凑）

目标：让用户一眼对照、快速 答え合わせ。一轮多题时**集中成一块**，不要每题换行长篇。

```
【答案核对｜玉手箱 四則逆算】
問1 → 16        問2 → 7.5       問3 → 240
問4 → 0.8       問5 → 64        問6 → 12
```

数值答案带单位 / 形式与原题一致（円・%・通り・cm 等）：

```
【答案核对｜SPI 非言語】
問1 → 3,200円   問2 → 15通り    問3 → イ
問4 → 1/6       問5 → 時速 60km
```

选择题给选项符号即可（ア/イ/ウ 或 A/B/C，与原题一致）。
若某题不确定，标 `?` 并一句话说明：`問7 → ?（图表数字看不清，麻烦确认纵轴单位）`。

---

## 模式 B：附中文解题过程

每题三段式。先汇总答案，再逐题展开。

```
【答案汇总】問1→B　問2→3,200円　問3→ア

────────────────
■ 問2  答案：3,200円

[题型] SPI 非言語・損益算
[步骤]
1. 原価を x とする。定価 = x×1.25（25%増し）
2. 売価 = 定価×0.9（1割引）= x×1.25×0.9 = 1.125x
3. 利益 400円 → 1.125x − x = 0.125x = 400 → x = 3,200
[答案] 原価 = 3,200円
[原题关键词] 原価・定価・利益・1割引き
```

要点：
- **答案醒目**放最前。
- 步骤用中文，但保留日文术语（損益算・定価・割引き 等），方便回到练习册。
- 每题给 `[原题关键词]`，对应日文原文里的关键字。
- 涉及图表的题，复述用到的关键数字（"グラフより 2020 年 = 480 万"），便于用户核对你有没有读错图。

---

## 通用约定

- 题号沿用原题（問1 / Q1 / ① / (1) 等）。原题没编号就按出现顺序编 `①②③`。
- 一轮结束可补一句弱项提示（可选）：如"这组損益算的'割引きの基準'容易错，建议重点练 `solutions/spi-nonverbal.md` 的损益算部分"。
- 截图题：先把识别出的题干/数字简述一句再给答案，避免 OCR 误读直接影响结论。
- 不确定时**显式说不确定**，不要编一个像样的答案。
